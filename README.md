 Akan Name Generator

 Project Description

The Akan Name Generator is a simple web application that calculates a user's Akan name based on their date of birth and gender. Akan names originate from Ghanaian culture, where children are named according to the day of the week they are born.

This project uses HTML, CSS, and JavaScript to create an interactive and visually appealing experience with animated background petals and a clean UI.
